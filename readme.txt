# SOC Tool - Security Incident Monitoring

## Overview

This tool helps monitor system events, such as failed login attempts, unusual network activity, and system health metrics. It provides real-time alerts and can be used for basic Security Operations Center (SOC) monitoring.

### Features:
- **Failed Login Attempts**: Monitors authentication logs to detect multiple failed login attempts.
- **Network Monitoring**: Detects abnormal spikes in network traffic.
- **System Health Monitoring**: Checks CPU and memory usage, sending alerts if thresholds are exceeded.
- **Alerts**: Sends email or Slack notifications when suspicious activity or system issues are detected.
